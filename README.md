a telegram user-bot, based on telethon, forwards your private messages to a group ,

as well as the ability to download and send self-destructing message.
Forwarded messages are sent to the group along with their name and user ID (for when the user deletes their account or closes their forwarding)

### **Install required packages:**

#### **_install in termux:_**
**run below commands in termux terminal :**

`pkg update && pkg upgrade -y && pkg install git python -y
`
and `pip install telethon`

Then clone the repository:  
`git clone https://github.com/dasalah/Auto-Forward-Telegram-Bot.git
cd Auto-Forward-Telegram-Bot `  
run python file:  
`python3 main.py
`
